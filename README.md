# 奶龙贪吃蛇 🐍

搞怪风贪吃蛇小游戏，手机电脑都能玩。

- 蛇头与豆子：微信照片（已嵌入页面）
- 背景音乐：《奶龙贪吃蛇》循环播放
- 电脑：**点鼠标**顺时针转向；手机：**点屏幕空白处**顺时针转向（也可以滑动屏幕）

## 玩法
- 每点一下，蛇顺时针转 90°（右→下→左→上→右）
- 吃到豆子加分，蛇越来越长、越来越快
- 撞墙或咬到自己就结束，点"再来一局"继续
- 空格开始/暂停，回车重开；最高分自动保存在浏览器里
